# Services

This section introduces the Datalayer services you deploy on top of your Kubernetes cluster.

Use it as your service map before running Plane deployment commands.

Services are grouped in three layers:

1. System services: cluster foundations such as ingress, certificates, storage and observability.
2. Core services: IAM, operator, runtimes, spacer, contents, library, AI agents, functions, scheduler, spider, manager, status.
3. Optional and addons: extra capabilities you enable depending on your use case.

## Recommended First Deployment Order

1. System Layer First:
	- [Cert Manager](/services/system/cert-manager/)
	- [Ingress](/services/system/ingress/)
	- [Solr](/services/system/solr/)
	- [OTEL](/services/system/otel/)
	- [Local CSI Driver](/services/system/local-csi/) — designed, not yet shipped; needed only for Local Mounts
2. Core Platform Layer:
	- [Datalayer IAM](/services/iam/)
	- [Datalayer Operator](/services/operator/)
	- [Datalayer Runtimes](/services/runtimes/)
	- [Datalayer Spacer](/services/spacer/)
	- [Datalayer Contents](/services/contents/)
	- [Datalayer Library](/services/library/)
3. Optional Services and Addons:
	- [Addons](/services/addons/)

## Minimum Service Set

For a base deployment, start with:

1. [Cert Manager](/services/system/cert-manager/)
2. [Ingress](/services/system/ingress/)
3. [Solr](/services/system/solr/)
4. [Datalayer Operator](/services/operator/)
5. [Datalayer IAM](/services/iam/)
6. [Datalayer Runtimes](/services/runtimes/)
7. [Datalayer Contents](/services/contents/)
8. [Datalayer AI Agents](/services/ai-agents/)

Each service page below documents purpose, deployment details, and operational checks.

## Terraform-First Workflow (AWS)

:::tip Terraform-First Workflow (AWS)

Before deploying services with Plane, provision the infrastructure and Kubeadm cluster:

```bash
cd terraform
terraform init
terraform apply
./generated/clouder-kubeadm-setup.sh
export KUBECONFIG=~/.clouder/kubeadm/1000 4 24 27 30 46 122 135 136 137 999 1000terraform output -raw cluster_name)/kubeconfig
kubectl get nodes -o wide
```

Then deploy all services in one pass:

```bash
./generated/plane-deploy-all-services.sh
```

:::
