# ☰ 🎛️ Datalayer Manager

<Stack direction="horizontal" alignItems="flex-start" padding="none" style={{marginBottom: 30}}>
  <Label color="blue">Kubernetes</Label>
  <Label color="red">REST API</Label>
</Stack>

`Datalayer Manager` is an API and UI (User Interface) to manage the Datalayer services. It is also responsible for the observability of the services. The observed metrics are used for the monitoring, alerting and billing.

## Deploy Datalayer Manager

<Tabs groupId="k8s">
  <TabItem value="plane" label="Plane" default>
```bash
plane up datalayer-manager
```
  </TabItem>
  <TabItem value="terraform" label="Terraform">
```bash
cd terraform
...
```
  </TabItem>
</Tabs>
