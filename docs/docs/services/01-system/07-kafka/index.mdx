# ☰ 🪳 Datalayer Kafka

[Apache Kakfa](https://kafka.apache.org) is an open-source distributed event streaming platform used by thousands of companies for high-performance data pipelines, streaming analytics, data integration, and mission-critical applications.

Define the pub sub engine as `kafka`.

```bash
DATALAYER_PUBSUB_ENGINE=kafka
```

Install Kakfa with the [Strimzi Operator](https://strimzi.io).

<Tabs groupId="k8s">
  <TabItem value="plane" label="Plane" default>
```bash
plane up datalayer-kafka
```
  </TabItem>
  <TabItem value="helm" label="Helm">
```bash
cat << 'EOF' > /tmp/values.yaml
...
EOF
export RELEASE=datalayer-kafka
export NAMESPACE=datalayer-kafka
...
```
  </TabItem>
  <TabItem value="terraform" label="Terraform">
```bash
cd terraform
terraform init
terraform apply
./generated/clouder-Kubeadm-setup.sh
export KUBECONFIG=~/.clouder/kubeadm/<cluster-name>/kubeconfig
./generated/services/deploy-datalayer-kafka.sh
```
  </TabItem>
</Tabs>

Check the availability of the Kafka Pods.

```bash
kubectl get pods -n datalayer-kafka
```

To interact with Kafka, you first need to port-forward.

```bash
plane pf-kafka
```
