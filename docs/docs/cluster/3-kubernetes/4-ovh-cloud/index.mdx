# 🚧 Datalayer on ☸️ OVHcloud

Datalayer can be deployed on OVHcloud Kubernetes infrastructure.

This page is being expanded. In the meantime, use this sequence:

1. Prepare requirements from [Requirements](/cluster/requirements/).
2. Provision your cluster with a Kubernetes version compatible with Datalayer.
3. Configure ingress, certificates, storage, and observability from [Services](/services/).
4. Use [Deployments](/deployments/) to deploy the platform components.

For production guidance specific to OVHcloud networking and security policies, contact [Support](/support/).
