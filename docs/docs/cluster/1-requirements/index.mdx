# Requirements

Review carefully this section before starting anything to ensure you meet all the requirements.

You need a few command Line Interfaces (CLI) on your local machine to run the deploy and management commands.

For the AWS infrastructure path, Terraform CLI is required in addition to Clouder, Plane, kubectl, and Helm.

Please request [our support](/support) if you are facing any issue or have questions.
