# ☸️ Cmctl CLI

You need [Cmctl](https://github.com/cert-manager/cmctl/releases) to renew the endpoints SSL certificates.

Follow the official documented steps to install them.

Optionally, we provide a onliner with the [Clouder CLI](/cluster/requirements/clouder/).

```bash
# Install Cmctl with Clouder.
clouder cmctl install
```
