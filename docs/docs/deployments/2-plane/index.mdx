# 🛫 Deploy with Plane

You will invoke plane `up` or `down` command to deploy or tear down a specific service.

For example to deploy and undeploy the Datalayer IAM sevice, use the following commands.

```bash
# Deploy datalayer-iam for example.
plane up datalayer-iam
```

```bash
# Tear down datalayer-iam for example.
plane down datalayer-iam
```

Follow the steps to deploy the [complete range of services](/services/).


Plane is using Helm charts behind the scene. Once the services are deployed, you can list them.
