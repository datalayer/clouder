# ☁️ Clouder CLI

To ease the cluster creation, you can use the `Clouder` CLI.

:::note

Clouder is optional and you can install the listed requirements without Clouder with the [listed Kubernetes CLI tools](/platform/kubernetes/requirements/cli).

:::

```bash
# You need `python>=3.9` and `pip` on your machine.
pip install clouder
```

```bash
$ clouder about
```
