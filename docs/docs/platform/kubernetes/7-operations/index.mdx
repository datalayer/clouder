# Operation

## SLA

The Service Level Agreement (SLA) depends on how the Platform Operator manages the Nodepools.

## Status Page

The availabilty of the online Datalayer services can be viewed on this [Status page](https://status.datalayer.run).

## Availability

The [availabity](/platform/kubernetes/operations/availablity) depends on how the Platform Operator manages the Nodepools.

The Platform Operator is responsible to provision the hardware resources (CPU/GPU and memory) to serve new Runtimes.

## Performance

The response time of the Datalayer services need to be [monitored](/platform/kubernetes/operations/observability) to ensure they respond fast enough.

Any deviation to the standard or slow response times can [be reported](/professional-services/support) to Datalayer.

## Support

We offer professional support agreements with various SLA in terms of issues handling terms. [Contact us](/professional-services/support) to know more.
