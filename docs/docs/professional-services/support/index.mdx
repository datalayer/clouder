# Support

The easiest way to get support on a specific open source component is to open an issue in the Datalayer [open source repositories](https://github.com/datalayer).

For other requests, use the [support repository](https://github.com/datalayer/support) to create and track feature requests and reports.

- [Open an issue](https://github.com/datalayer/support/issues/new/choose) if the scope is clear.
- [Open a discussion](https://github.com/datalayer/support/discussions/new) if you'd like to discuss and get more opinions before opening an issue.

You can also send feedback or questions to our [Bluesky account](https://bsky.app/profile/datalayer.ai).

If you need priority issue handling or regular support calls, we offer sponsorship options via the [GitHub Sponsors program](https://github.com/sponsors/datalayer). For closer interactions, we also offer support contracts. Send an email to <a href="https://datalayer.ai/contact">Contact us</a> to learn more.

If those options do not fit your requirements, we are here to help! Please book a call to discuss.
