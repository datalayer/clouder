# Operations

## SLA

The Service Level Agreement (SLA) depends on how the Platform Operator manages node pools.

## Status Page

The availability of the online Datalayer services can be viewed on this [Status page](https://status.datalayer.run).

## Availability

The [availability](/operations/availability/) depends on how the Platform Operator manages node pools.

The Platform Operator is responsible to provision the hardware resources (CPU/GPU and memory) to serve new Runtimes.

## Performance

The response time of Datalayer services needs to be [monitored](/operations/observability/) to ensure they respond fast enough.

Any significant slowdown or unexpected behavior can [be reported](/professional-services/support) to Datalayer.

## Support

We offer professional support agreements with different SLA options for issue handling. [Contact us](/professional-services/support) to learn more.
