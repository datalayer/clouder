# Datalayer Integrations

This section explains how Datalayer integrates with external platforms and ecosystem tools.

The integration guides focus on connecting existing user environments to Datalayer services without changing your core platform architecture.

## Available integration guides

The current integration catalog includes:

1. [JupyterHub Integration](/integrations/jupyterhub/): connect Datalayer runtimes and services to JupyterHub-based user workflows.

## Recommended integration sequence

1. Deploy and validate the Datalayer platform first: [Deployments](/deployments/) and [Services](/services/).
2. Configure identity, runtime, and networking prerequisites for your external platform.
3. Apply the integration guide for your target framework.
4. Validate end-user flow (authentication, runtime launch, and workload execution).

As new frameworks are added, they will appear under this page.

If you need architecture review or implementation help, contact [Support](/professional-services/support/).
