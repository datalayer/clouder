# clouder info

Show information about the current Clouder context and user.

## Commands

### `clouder info ctx`

Show detailed info about the current context.

```bash
clouder info ctx
```

Displays the active cloud provider, project/subscription, and configuration details.

---

### `clouder info me`

Show current user information.

```bash
clouder info me
```

Displays the authenticated user for the current cloud provider.

---

## Example

```bash
# Check what context you're working in
clouder info ctx

# Check who you're authenticated as
clouder info me
```
